Concept 1 ★ Recommended
Single bar · Segmented preview toggle · Draggable split
All controls in one 52px bar. Preview toggle is a 3-state segmented control (form / split / preview). On portrait or narrow screens the split becomes top-bottom with the same draggable handle. Progress ring is clickable — opens inline N/A panel.
✓ Everything accessible ✓ Draggable split works on all sizes ✓ Export + Publish in one dropdown ✓ Save disappears after publish ✗ Preview toggle is small on mobile

Concept 2
No preview toggle in the bar — floating FAB button instead
Preview is triggered by a floating action button (bottom-right of the form panel). Works identically on desktop, tablet, and phone — FAB is always reachable. Tapping opens the preview as an overlay/drawer. Bar is maximally clean.
✓ Cleanest bar possible ✓ FAB always reachable on any screen size ✗ Side-by-side split harder to access (2 taps vs 1) ✗ FAB can cover form content

Concept 3
Layout options collapsed into the ··· menu
Preview layout modes (side-by-side, top-bottom, form only, preview only) live inside the ··· menu alongside Home, Reset, and Version History. Single overflow menu handles everything. Bar is the leanest of the three — just ring, Save, Export, ···.
✓ Fewest visible controls ✓ Layout switching still possible ✗ Preview mode switching requires menu open ✗ Less glanceable
